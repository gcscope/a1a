working on rantstuff.com

07/26/2026

Yesterday was my site's one month anniversary. I didn't post anything for it, but I have been writing this blog for a few days, and doing other stuff.

I've been working on rantstuff.com for the last week, and I've gotten a lot done so far. Although rantstuff uses the a1a framework, I've taken rantstuff.com on a whole different route compared to a1a. For starters, I purchased my first web server, a VPS on DigitalOcean. In the last blog, I mentioned myself wanting to self-host the site, but the more I thought about it, the more I realized it wasn't the best idea short and long term. With a vps, I can still do the things I would've been able to do on a self-hosted server, but for a lot cheaper. The server i currently have is $6 a month, If I bought a mini pc for the server, I would've put over $100 down on something I haven't even started yet. And what if rantstuff doesn't do well? That would be wasted money. At least the vps is 6 bucks a month. So if I decide to cancel the server after a few months, I will have saved money long term.

DESIGNING THE SITE

I used photoshop to design the site, It only took me about an hour to come up with the design. I then put it into Claude and asked it to recreate what I had in the image, but it looked like shit, so I duplicated the a1a index page and used that as a framework. I would ask Claude to move text or add things, and I would alter them manually based off of my designs. This method has been the most efficient for me, as I'm 70% done with the site.

Since this is on a vps, instead of using Firebase for the online part, It's coded entierly with PHP. I don't know a single line of PHP, so using Claude saved me a bunch of time. It also helped me set up the email service, setting up the oauth client, and turnstile. I'm gonna try to get the site released this week and you will be able to acces it by visiting rantstuff.com, or on the other stuff page.
